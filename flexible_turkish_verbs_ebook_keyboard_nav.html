Flexible Turkish Verbs

51 high-frequency Turkish verbs whose natural English translation changes with context. Each English equivalent includes multiple conversational examples.

How to use this book

Do not memorize one English word for each Turkish verb. Learn the pattern English word → context → Turkish example → natural English. The same Turkish verb can map to very different English verbs depending on what is happening in the sentence.
